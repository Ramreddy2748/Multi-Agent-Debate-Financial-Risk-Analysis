# Repository Cleanup Audit

This audit separates files needed to run the project from generated artifacts that should stay local, be regenerated, or be stored outside GitHub.

## Keep For Running The App

These are part of the current API-backed stock risk app.

- `src/api/server.py` - FastAPI backend and frontend/static mounting.
- `frontend/index.html`, `frontend/app.js`, `frontend/styles.css` - stock risk dashboard.
- `agents/orchestrator/critic_agent.py` - runs Fundamental, Market/News, Sentiment, Macro, and critic synthesis.
- `agents/orchestrator/debate_state_machine.py` - debate-style contradiction and revision flow.
- `agents/orchestrator/monitoring.py` - monitoring log support.
- `agents/orchestrator/verdict_report.py` - JSON/PDF verdict generation.
- `agents/orchestrator/policy_evidence.py` - Policy A-H evidence trail.
- `agents/fundamental/finbert.py` - FinBERT training/inference wrapper.
- `agents/sentiment/finbert.py` - ProsusAI/finbert headline sentiment specialist.
- `agents/macro/agent.py` - macro agent logic and optional external model path.
- `agents/*.py` - thin compatibility wrappers for old commands/imports.
- `config.py`, `requirements.txt`, `.env` locally - configuration and dependencies.

## Keep For Data Pipeline

These are useful if you want to rebuild the data layers.

- `ingest.py` - Bronze ingestion from Yahoo, SEC EDGAR, FRED, and NewsAPI.
- `clean.py` - Silver layer cleaning and feature engineering.
- `eda.py` - Gold risk scoring/EDA.
- `pipeline_large_scale.py` - large ticker universe pipeline runner.
- `tickers.py` - S&P 500/universe ticker utilities.
- `newsapi_only.py` - targeted NewsAPI refresh utility.
- `split.py`, `stats_summary.py` - dataset split and summary scripts.

## Keep For Training Or Reproducing Models

These are useful, but they are not needed every time the frontend runs.

- `agents/fundamental/build_finetune_data.py` - builds FinBERT fundamental JSONL.
- `agents/market/build_finetune_data.py` - builds Qwen LoRA market/news JSONL.
- `agents/market/finetune_lora.py` - generic LoRA fine-tuning script.
- `agents/market/infer_lora.py` - standalone LoRA inference test script.
- `agents/fundamental/fundamental_finbert_colab.ipynb` - Colab workflow for FinBERT training.
- `agents/market/market_sentiment_lora_colab.ipynb` - Colab workflow for market/news LoRA.
- `agents/market/market_mistral_training.ipynb` - Colab workflow for Mistral market/news LoRA.

## Generated Files That Should Not Be Committed

These files are useful locally but should be ignored by GitHub because they are generated, large, or environment-specific.

- `.venv/` - local Python environment; recreate with `python3 -m venv .venv` and `pip install -r requirements.txt`.
- `__pycache__/`, `*.pyc` - Python bytecode cache.
- `data/bronze/` - raw API extracts; can be regenerated by ingestion.
- `data/silver/` - cleaned outputs; can be regenerated from Bronze.
- `data/silver_parquet/` - Parquet copies; generated analytics artifacts.
- `data/reports/` - generated plots/reports.
- `data/verdicts/` - generated JSON/PDF verdicts.
- `mlruns/`, `mlflow.db`, `data/gold/_mlflow_artifacts/` - local MLflow tracking artifacts.
- `pipeline.log`, `pipeline_large_scale.log`, `pipeline_progress.json` - local run logs/state.
- `market_sentiment_lora.zip` - downloadable model archive; keep in Drive/Hugging Face/artifact storage instead.
- `outputs/` - duplicate training export folder.
- `models/**/checkpoint-*/` - intermediate training checkpoints.
- `*.safetensors`, `*.pt`, `*.pth`, `*.bin` - large model/training weights.

## Local Files Required If You Want Model Inference

These are needed locally only if you want local inference. They should not be committed to GitHub.

- `models/fundamental_agent_finbert/` - final FinBERT model used by the Fundamental Agent.
- `models/market_sentiment_lora/` - final Qwen LoRA adapter if running local inference. If using Colab/ngrok, the local app only needs `MARKET_LORA_REMOTE_URL`.

Recommended storage: Google Drive, Hugging Face Hub, GitHub Releases, or another artifact store. The repo should document where to download them, not store them directly.

## Biggest Cleanup Candidates

These are the safest space-saving removals after confirming the final models are backed up.

- `outputs/` - duplicate of `models/fundamental_agent_finbert`; about 5.3GB.
- `models/fundamental_agent_finbert/checkpoint-*` - intermediate FinBERT checkpoints; final model remains in the model root; about 4GB+.
- `models/market_sentiment_lora/checkpoint-*` - intermediate LoRA checkpoints; final adapter remains in the model root; about 400MB+.
- `market_sentiment_lora.zip` - archive copy of the model folder; about 461MB.
- `__pycache__/` and `agents/__pycache__/` - safe generated cache cleanup.
- `data/verdicts/` - generated outputs; keep sample verdicts only if needed for demo.

## Git Warning

The `.git/` folder is currently very large because generated data/model artifacts were likely committed at some point. Deleting files from the working tree will not shrink `.git/`. To truly shrink the repository later, use Git LFS or a history cleanup tool such as `git filter-repo`, but only after coordinating with teammates because it rewrites history.
